# Atlas RAG Assistant

A web interface for a Groq-powered Retrieval-Augmented Generation assistant using ChromaDB and Sentence Transformers.

## Deploy

This repository is configured for a Python web service. Set `GROQ_API_KEY`, `APP_PASSWORD`, and `SESSION_SECRET` as environment variables in the hosting provider. Never commit API keys.

See the project ZIP from the ChatGPT conversation for the full application files and deployment configuration.
